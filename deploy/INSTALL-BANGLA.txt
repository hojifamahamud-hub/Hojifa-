কীভাবে লাগাবেন:
  ১) File Manager-এ আপনার আগের Laravel ফোল্ডারটায় যান
     (যেখানে artisan, composer.json, vendor আছে)।
  ২) এই জিপটা সেখানে আপলোড করুন -> Extract -> Overwrite করুন।
  ৩) ডেটাবেস আপডেট (যেকোনো একটি):
       (ক) phpMyAdmin -> আপনার ডিবি সিলেক্ট করুন -> Import -> install.sql
           (আবার ইমপোর্ট নিরাপদ - আগের ডেটা ওভাররাইট হবে না)
       (খ) বা SSH/Terminal থাকলে: php artisan migrate
  ৪) .env খুলে শুধু এই লাইনে নিজের ডিবি পাসওয়ার্ড দিন:
       DB_PASSWORD=আপনার_ডিবি_পাসওয়ার্ড
     (DB_DATABASE ও DB_USERNAME আগেই ঠিক আছে: mahmudsu_hojifa)
  ৫) storage ও bootstrap/cache ফোল্ডারে 755 পারমিশন দিন।
  ৬) ক্যাশ পরিষ্কার করুন (SSH থাকলে):
       php artisan config:clear && php artisan cache:clear
     (না হলে cPanel থেকে অ্যাপ একবার রিস্টার্ট করলেই হবে)
  ৭) ডোমেইন ওয়েব রুট ঠিক করুন:
       সেরা পথ: cPanel -> Domains -> home.mahmudsupport.xyz -> Document Root
                 বদলে দিন: <laravel-ফোল্ডার>/public
       না হলে: এই জিপের public/ ভেতরের সব ফাইল কপি করে
               আপনার ডোমেইন রুট ফোল্ডারে পেস্ট করুন।
  ৮) সাইট: https://home.mahmudsupport.xyz/  |  অ্যাডমিন: /admin/login
       admin@mahmudsupport.xyz / Admin@12345  (প্রথম কাজ: পাসওয়ার্ড বদলান)
