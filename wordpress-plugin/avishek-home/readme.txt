== বাংলা ব্যবহার গাইড ==

১. Plugins → Add New → Upload Plugin → Hojifa-wordpress-plugin.zip → Install Now → Activate

২. হোমপেজে বসাতে:
   - একটা তাজা পেজ বানান (Pages → Add New), টাইটেল দিন (যেমন: Home)
   - এডিটরে শুধু এই লাইনটা লিখুন: [avishek_home]
   - Publish করুন
   - Settings → Reading → Your homepage displays: A static page → Homepage: সেই পেজ → Save
   (টাইটেল দেখাতে চাইলে না দেখাতে চাইলে — থিম অনুযায়ী; চাইলে পেজ টাইটেল খালি রাখুন)

৩. সবকিছু কাস্টমাইজ:
   - অ্যাডমিন মেনু বাম পাশে "Avishek Home" → হোমপেজ কাস্টমাইজ
   - হিরো, প্ল্যাটফর্ম, অর্জন, About, Skills, Services, Pricing,
     ক্যালকুলেটর, পোর্টফোলিও, কেস স্টাডি, টেস্টিমোনিয়াল, ভিডিও,
     প্রোফাইল, ইনসাইট, FAQ, মিটিং, নিউজলেটার, কন্টাক্ট, ফুটার — সব এডিটযোগ্য
   - তালিকার ঘরে প্রতি লাইনে একটা করে আইটেম; ফরম্যাট প্রতিটা ঘরের নিচে লেখা যেমন: নাম|দাম|...
   - ডার্ক মোড: বাটন দিয়ে ভিজিটর নিজেই টগল করবে; চাইলে "ডিফল্ট ডার্ক মোড" চালু করে দিন
   - সেকশন লুকাতে: সংশ্লিষ্ট "দেখাও" চেকবক্স খুলে দিন

৪. ফর্মের রিকোয়েস্ট দেখতে:
   - "Avishek Home" → রিকোয়েস্ট / লিড
   - কন্টাক্ট, মিটিং বুকিং ও নিউজলেটার সাবমিশন এখানে জমা হয়
   - নোটিফিকেশন ইমেইল দিলে প্রতিটা সাবমিশনে মেইলও যাবে
